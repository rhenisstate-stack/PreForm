## 2. Issue A — Gateway HMAC Canonicalization & Verification

### 2.1 Implementation Audit
- **Signer:** `apps/web/src/lib/api-client.ts` (`createCanonicalGatewayAuthHeaders`)
- **Verifier:** `apps/api/Services/PrepfordAuthHandler.cs` (`HandleAuthenticateAsync`)

#### Canonical Representation Specification
Both signer and verifier construct an identical deterministic string separated by Unix newlines (`\n`):
```text
{timestampSeconds}
{httpMethod}
{canonicalPath}
{nonce}
{bodySha256Hash}
{gatewayUserId}
{gatewayEmailNormalized}
{gatewayRoleNormalized}
```

#### Detailed Contract Invariants
| Property | Client Signer (`api-client.ts`) | Server Verifier (`PrepfordAuthHandler.cs`) | Status |
|---|---|---|:---:|
| **HTTP Method** | `(options.method \|\| "GET").toUpperCase()` | `Request.Method.ToUpperInvariant()` | **MATCH** |
| **Canonical Path** | `normalizedEndpoint` (includes raw query string with leading `?`) | `string.IsNullOrEmpty(rawQuery) ? path : $"{path}{rawQuery}"` | **MATCH** |
| **Query String** | Transmitted as formatted in endpoint string | `Request.QueryString.Value` preserves raw transmitted bytes | **MATCH** |
| **Timestamp** | Unix timestamp (seconds) `Math.Floor(Date.now() / 1000)` | `long.TryParse(timestampStr, out var timestampSeconds)` | **MATCH** |
| **Timestamp Window** | Enforces $\pm 60$ seconds clock skew window | `Math.Abs(nowSeconds - timestampSeconds) > 60` returns 401 | **MATCH** |
| **Nonce Generation** | `crypto.randomBytes(16).toString("hex")` | Checked against `IGatewayReplayProtection` | **MATCH** |
| **Body Hash** | SHA-256 hex digest (`computeBodySha256`) | Lowercase hex matching `EmptyBodySha256` constant | **MATCH** |
| **Identity Normalization** | `userId.trim()`, `email.trim().toLowerCase()`, `role.trim().toLowerCase()` | `gatewayUserId.Trim()`, `gatewayEmail.Trim().ToLowerInvariant()`, `gatewayRole.Trim().ToLowerInvariant()` | **MATCH** |
| **HMAC Digest** | HMAC-SHA256 lowercase hex string | HMAC-SHA256 lowercase hex string | **MATCH** |
| **Comparison** | N/A (Server performs verification) | `CryptographicOperations.FixedTimeEquals` (constant time) | **MATCH** |
| **Secret Validation** | Throws in production if `GATEWAY_SHARED_SECRET` is missing | Fails closed with 401 if unconfigured outside Dev/Testing | **MATCH** |

### 2.2 Replay Protection Analysis
- **Service:** `IGatewayReplayProtection` (`GatewayReplayProtection`) registered as Singleton in `Program.cs`.
- **Mechanism:** `ConcurrentDictionary<string, long>` storing `{ nonce: timestampSeconds }`.
- **Pruning:** Nonces older than 120 seconds are pruned periodically when the cache exceeds 500 entries.
- **Architectural Observation:** Replay tracking is process-local. In a single-instance container or sticky-session deployment, replay prevention is 100% effective. In a distributed multi-instance deployment without sticky sessions, independent API replicas maintain isolated memory stores. Recommending external Redis-backed replay protection for horizontally scaled multi-region clusters in future phases.

## 3. Issue B — Next.js Instant-Navigation Validation Remediation

### 3.1 Implementation Audit

#### Component Structure Verification
```tsx
// admin-shell.tsx (commit f9db40e)
const gatedChildren = (
  <div hidden aria-hidden="true">
    {children}
  </div>
);

if (isLoading) {

    <>
      {gatedChildren}

    </>

if (!isAuthenticated || !user) {
  return (
    <>
      {gatedChildren}
      <div className="mx-auto max-w-xl py-20 px-4 text-center">
        {/* Auth Gate Panel */}
      </div>
    </>
  );

if (!authorized || !capabilities.canViewOverview) {
  return (
    <>
      {gatedChildren}

      </div>
    </>

```

#### Security & Visual Invariant Verification
1. **DOM Tree Presence:** `{children}` is present in the rendered React tree during Next.js App Shell analysis, resolving `createUnrenderedSegmentError`.
2. **Visual Invisibility:** Rendered inside `<div hidden aria-hidden="true">`, ensuring child components have `display: none`, are excluded from accessibility trees, and cannot receive focus or pointer events.
3. **Mutation Safeguard:** Child components do not fire data mutation queries automatically upon mount; data fetching is guarded by `enabled: isAuthenticated && capabilities.canViewExaminations` in TanStack Query.
4. **Suspense Coverage:** `apps/web/src/app/admin/examinations/page.tsx` encapsulates `AdminExaminationsClient` within `<Suspense fallback={<BrandedLoading message="Loading examination catalogue..." fullScreen={false} />}>`, fully satisfying Next.js `useSearchParams` dynamic prerender requirements.
5. **No Opt-Out:** `export const instant = false` is **not** present. The route remains 100% compliant with Next.js instant SPA transitions.
