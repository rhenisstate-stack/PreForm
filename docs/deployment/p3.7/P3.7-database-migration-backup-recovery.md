### 2.2 Critical Schema Safety Findings
1. **Zero Destructive DDL:** Zero `DROP TABLE`, zero `DROP COLUMN`, and zero column narrowing operations exist across the entire migration history.
2. **Nullable / Default Additions:** In migration 8 (`AddExaminationLifecycleAndSnapshot`), newly introduced columns on `Exams` (`ExaminationId`, `RevisionNumber`, `LifecycleState`, `ConcurrencyToken`) are either nullable foreign keys or possess safe default values.
3. **Partial Unique Indexes:** Verified that partial indexes `IX_Exams_ExaminationId_ActiveDraft` (`WHERE "LifecycleState" = 1`) and `IX_Exams_ExaminationId_SinglePublished` (`WHERE "LifecycleState" = 4`) enforce lifecycle business constraints at the datastore level without full table locking.
4. **Deterministic Rollback Compatibility:** The application code can be rolled back to any previous version without requiring schema rollbacks because all changes are additive and backward-compatible.

## 4. Backup Strategy, Objectives & Runbook

### 4.1 Target Objectives
- **Target RPO (Recovery Point Objective):** $\le 15$ minutes (with continuous WAL archiving, RPO $\le 60$ seconds).
- **Target RTO (Recovery Time Objective):** $\le 60$ minutes for logical restoration; $\le 15$ minutes for storage snapshot / replica promotion.

### 4.2 Pre-Deployment Snapshot Execution
Executed immediately prior to staging or production migration:
```powershell
$timestamp = Get-Date -Format "yyyyMMdd_HHmmss"
$backupFile = "prepford_staging_backup_pre_deploy_${timestamp}.dump"

# Custom compressed format pg_dump
pg_dump -h <staging-host> -U <staging-user> -d prepford_staging -Fc -Z 6 -f $backupFile

# Generate cryptographic checksum
Get-FileHash $backupFile -Algorithm SHA256 > "${backupFile}.sha256"
```

### 4.3 Database Restore Runbook
1. **Isolate Target Database:**
   ```sql
   SELECT pg_terminate_backend(pid) FROM pg_stat_activity WHERE datname = 'prepford_recovery' AND pid <> pg_backend_pid();
   DROP DATABASE IF EXISTS prepford_recovery;
   CREATE DATABASE prepford_recovery;
   ```
2. **Execute Restoration:**
   ```powershell
   pg_restore -h <db-host> -U <db-user> -d prepford_recovery --verbose --clean --if-exists --no-owner --no-privileges $backupFile
   ```
3. **Verify Data Fidelity Post-Restore:**
   ```sql
   SELECT count(*) FROM information_schema.tables WHERE table_schema = 'public'; -- Must equal 32
   SELECT count(*) FROM public."__EFMigrationsHistory";                        -- Must equal 9
   SELECT count(*) FROM public."Examinations";
   SELECT count(*) FROM public."Exams";
   SELECT count(*) FROM public."ExamQuestions";
   ```
